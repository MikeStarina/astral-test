## Функции колбэки Напишите функцию, которая реализует подтверждение опредленного действия (например, вы точно хотите удалить выбранный элемент?) в качестве параметров фукнция должна принимать: вопрос; функцию-колбэк, вызываемую если пользователь подтвердит действие; функцию-колбэк, вызываемую, если пользователь отклонит действие. Для подтверждения пользователем – используйте стандартную функцию prompt.

```js
function confirm(question, callback) {
  const answer = prompt(question)
  const normalized = (answer ?? '').trim().toLowerCase()
  const confirmed = 'да' === normalized

  if (confirmed) {
    callback()
  }
}

confirm(
  'Удалить? (да/нет)',
  () => console.log('Удалено'),
)
```

## Объекты, методы объектов, this. Что такое this? Приведите пример потери this. Приведите пример решения проблемы потери this через привязку контекста и стрелочные функции.

this - контекст вызова функции - хранит инфу того блока где была вызвана

```js
const admin = {
  name: 'Mike Starina',
  printName() {
    console.log(this.name)
  },
}

admin.printName() // "Mike Starina"

const otherFunc = user.printName
otherFunc() // undefined
```
привязка контекста

```js
const solution = user.printName.bind(user)
solution() // "Mike Starina"
```

## Что такое TypeScript? Для чего введен? В чем отличие от JS?

## Расскажите про обобщенные типы (generics) в TypeScript, приведите пару примеров.

Dозможность иснольвоать скажем функцию с разными типами или один тип с разными внутри

```ts
  return value
}

interface ISample<T> {
  data: T
  // other keys
}
```
